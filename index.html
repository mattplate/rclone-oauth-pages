rclone pihomeserver — backup personal

Esta aplicación es una herramienta de uso estrictamente personal y doméstico. Se utiliza con rclone para sincronizar una copia de seguridad cifrada de un disco duro propio ("Digital Ark") hacia Google Drive.

No tiene usuarios externos, no tiene fines comerciales y no comparte datos con terceros.
